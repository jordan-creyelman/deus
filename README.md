# DEUS ARCHIVE

DEUS ARCHIVE est une application JDR mobile-first développée sous la forme
d'une Progressive Web App.

## Stack technique

### Frontend

- Next.js
- TypeScript
- PWA

### Backend

- Django
- Django REST Framework
- PostgreSQL

### Infrastructure

- Docker
- Docker Compose
- Nginx
- GitHub Actions

## Structure

```text
backend/             API Django
frontend/            Application Next.js PWA
nginx/               Configuration du reverse proxy
.github/workflows/   Intégration continue
